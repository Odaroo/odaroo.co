# odaroo.co

The front page of Odaroo & Co.: a game-magazine style portfolio. Static files, no build step.
The games themselves live at https://play.odaroo.co.

- `index.html`, `paper.css`, `paper.js`: the page.
- `img/`: stills captured from the games. `art/`: the cartridges and the logo. `audio/`: two themes by Odaroo.
- `CNAME`: tells GitHub Pages this site answers at odaroo.co.

To change something, edit the file and push to `main`; GitHub Pages republishes in about a minute.
